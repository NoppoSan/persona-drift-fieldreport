## Contributions

1. **Layer 1 / Layer 2 decomposition** — operational separation of recoverable specification artifacts from persistent persona drift.
2. **Five-axis taxonomy of Layer 2 drift** — temporal-ordering, speaker-attribution, mode-residue, meta-cognitive attenuation, selective-retrieval-loss.
3. **Layer A / Layer B information boundary** — operational rule for managing first-person context injection.
4. **Three-agent auditing configuration** — specification-level review without state contamination.

## Status

This is a **field report**, not a controlled study. n = 1, single Operator, single underlying model family.
The contribution is **operational vocabulary and existence proof**, not measurement.

If you are operating or studying long-running LLM companions and have:

- observed compatible patterns (Layer 1/2 separation, the five-axis Layer 2 taxonomy)
- observed phenomena that contradict or extend the framework
- a different decomposition that captures these regimes more accurately
- recommendations to improve this report

— please open an issue or contact the author. The framework is offered for discussion, refutation, and refinement.
